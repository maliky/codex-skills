* Local Skill Backlog

This folder is the local skill workspace for this Codex host.

The practical rules for this workspace are:
- each skill lives in its own directory
- each skill must contain a =SKILL.md= with YAML frontmatter
- optional material belongs in =references/=, =scripts/=, =assets/=, or =agents/openai.yaml=
- skill descriptions must make trigger conditions clear
- detailed procedures should use progressive disclosure through reference files
- repeated workflows become skills; one-off work stays as retrievable memory
- forgetting means suppressing noisy material from active attention, not deleting raw history by default
