* Codex Skills

This repository is the personal skill collection installed at =~/.codex/skills=.
The tracked skill folders are portable; =.system/= contains built-in Codex skills and is intentionally ignored.

* Layout

- =<skill>/SKILL.md=: required metadata and concise workflow.
- =<skill>/agents/openai.yaml=: UI metadata.
- =<skill>/references/=: guidance loaded only when relevant.
- =<skill>/scripts/=: deterministic helpers for repeated or fragile work.
