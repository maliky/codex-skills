* Codex Skills

This repository is the personal skill collection for this Codex host. It is checked out at =~/.codex/skills= so Codex can discover the skills directly after restart.

The tracked folders are portable skills that can be shared across hosts with Git. The local =.system/= folder contains built-in Codex skills and is intentionally not tracked by this repository.

* Directory Layout

- =<skill>/SKILL.md=: required skill entrypoint with YAML =name= and =description= frontmatter plus concise operating instructions.
- =<skill>/agents/openai.yaml=: UI metadata such as display name, short description, and default prompt.
- =<skill>/references/=: progressively loaded guidance for detailed workflows, edge cases, source priorities, and command routes.
- =<skill>/scripts/=: deterministic helpers for repeated or fragile operations.
- =.system/=: local built-in skills supplied by Codex; do not commit this directory here.
