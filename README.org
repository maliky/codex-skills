The main constraints repeated by the upstream spec are:
- each skill lives in its own directory
- each skill must contain a =SKILL.md=
- the =SKILL.md= must start with YAML frontmatter with at least =name= and =description=
- optional material should stay in =references/=, =scripts/=, =assets/=, and optionally =agents/openai.yaml=
- skill descriptions must say both what the skill does and when it should trigger
- skills should use progressive disclosure: keep =SKILL.md= lean and move detail to references
