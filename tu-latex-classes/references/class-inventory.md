# Class Inventory

Use this reference when deciding where to place a TU class or style fix.

- list affected classes (`tupolicy`, `tupolicymanual`, `tuprocedures`, `tuform`, `tumemo`, `tuminutes`)
- check whether curriculum classes are involved (`tuclgcurri`, `tuunivcurri`)
- avoid cross-editing more families than needed
- map each change to a specific document family before touching files
