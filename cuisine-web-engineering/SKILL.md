# Cuisine Web Engineering

Read `AGENTS.md`, `VIGNETTES-REVUE.org` when artwork is involved, the latest relevant `DEV.org` decisions and `README.org`. The website has explicitly approved colour collections with different purposes from the original monochrome book assets; verify the requested collection before choosing a style or production command.

## Workflow

1. Confirm the checkout, dirty work, requested recipe/category collection and whether the task is UI, artwork production or publication.
2. Preserve validated recipe facts and original assets. Trace every web derivative to its source and applicable review record.
3. Use the maintained catalogue, queue, builder and packaging paths; an image-generation success or a queue counter alone is not visual acceptance.
4. Complete the authorised queue through successive durable batches when requested, then verify the relevant UI and publication boundary.

## Routes

- **Colour artwork, batch continuation, visual review or rejected retries**: read [reviewed artwork](references/reviewed-artwork.md).
- **Catalogue, cooking navigation, private media, checks or releases**: read [site and release](references/site-and-release.md).
- **Original OCR/editorial sources or monochrome panels**: use [cuisine-book-engineering](../cuisine-book-engineering/SKILL.md).

## Report

Report the collection, verified progress from its queue/receipts, accepted or blocked work, checks and publication state. If blocked, leave the exact next recoverable action. Counts and current service state must come from current files/processes rather than old DEV entries.
